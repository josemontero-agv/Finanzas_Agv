1. Control de Acceso Roto (OWASP A01) Crítico

Descripción: Ausencia de validación de autenticación en endpoints de información financiera sensible.

app/treasury/routes.py

Múltiples endpoints como /report/account42 y resúmenes por proveedor carecen del decorador @require_login.

# ESTADO ACTUAL (Vulnerable)
@treasury_bp.route('/report/account42', methods=['GET'])
def report_account42():
    # Permite acceso público a CxP
app/exports/routes.py

El endpoint para exportar el reporte consolidado de tesorería a Excel puede ser consultado externamente.

# SOLUCIÓN REQUERIDA
from app.auth.security import require_login

@exports_bp.route('/treasury/excel', methods=['GET'])
@require_login
def export_treasury_excel():

2. Componentes Vulnerables (OWASP A06) Crítico

Descripción: Uso de librerías desactualizadas con vulnerabilidades públicas reportadas (CVE).

requirements.txt

El proyecto exige la versión 3.0.1 de Werkzeug. Esta versión padece de la vulnerabilidad CVE-2024-34069, la cual permite a un atacante consumir los recursos del servidor mediante un ataque de Denegación de Servicio (DoS) manipulando cabeceras HTTP.

# requirements.txt (Línea 5)
Werkzeug==3.0.1

# SOLUCIÓN REQUERIDA (Actualizar a versión parcheada)
Werkzeug>=3.0.6

3. Fallas Criptográficas y de Configuración Alto Riesgo

scripts/etl/etl_netted_sync.py

A02: Anulación global de certificados SSL. Facilita ataques Man-In-The-Middle y robo de credenciales de DB.

# Línea 12 - ELIMINAR INMEDIATAMENTE
import ssl
ssl._create_default_https_context = ssl._create_unverified_context

Solución: Instalar certificados corporativos raíz en el SO del contenedor (Dockerfile) en lugar de evadir la seguridad en Python.

config.py

A05: Fallback hardcodeado para la llave secreta en Producción. Permite falsificación masiva de sesiones.

# class ProductionConfig(Config)
app.config['SECRET_KEY'] = os.getenv('SECRET_KEY', 'production-secret-key')

# SOLUCIÓN:
secret = os.getenv('SECRET_KEY')
if not secret:
    raise ValueError("FATAL: SECRET_KEY no definido")
app.config['SECRET_KEY'] = secret
