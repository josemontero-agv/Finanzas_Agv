Diagnóstico & Justificación

¿Por qué este proyecto es crítico para la operación actual?

Limitación de Odoo v17

El procesamiento de reportes de antigüedad (aging) en Odoo causa bloqueos en la base de datos de producción debido a cálculos complejos de SQL en tiempo real sobre miles de registros.

Rigidez en Auditoría

La imposibilidad de generar reportes con "Fecha de Corte" histórica exacta (reversión de pagos) obliga al equipo a realizar cierres manuales en Excel que toman hasta 6 horas.

Latencia de Reportes Masivos

* Medición basada en reportes de +5,000 líneas de factura.

Prevención de Spam (RF-203)

El sistema bloquea envíos duplicados al mismo contacto en una ventana de 24 horas. Los estados se marcan como "Notificado" en Supabase Realtime para visibilidad de todo el equipo.
